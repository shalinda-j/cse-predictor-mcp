CSE Predictor MCP Server

Live Colombo Stock Exchange data and technical analysis over the Model Context Protocol.

Data is fetched live from the official CSE API — no simulated data. This is a technical-analysis tool, not financial advice.

API Endpoints

POST /api - MCP JSON-RPC endpoint (tools/list, tools/call)
GET /api/health - Health check

Tools

  • fetch_market_data - live ASPI, S&P SL20, turnover, status
  • get_company_data - live quote for a company
  • analyze_stock - technical indicators on real price history
  • predict_stock - technical-analysis directional outlook
  • screen_stocks - rank traded securities by live quote criteria
